上載方法（GitHub Pages，免費）
1. 開一個 GitHub 帳戶，例如 pixelcraftgames59。
2. 新增 repository，名稱一定要係「帳戶名.github.io」，例如 pixelcraftgames59.github.io，設為 Public。
3. Add file → Upload files，將呢個資料夾入面所有檔案同資料夾（唔包括呢個 README.txt）拖入去，撳 Commit。
4. 等一兩分鐘，打開 https://帳戶名.github.io/app-ads.txt 見到嗰一行字就成功。

App Store 的「開發者網站」要係 https://帳戶名.github.io/ （三隻遊戲同一個），AdMob 先搵到 app-ads.txt。
已上架的遊戲改網址後，要喺 App Store Connect 更新 App 資訊（私隱政策網址可以唔使送審即改）。
